# FDA. DRUG SHORTAGES ANALYSIS

## Problem
The format of the initial file is JSON. It contains columns with lists, and a large amount of missing data makes the file unreadable, not to mention finding any business value.

## Solution/Opportunities
The dashboard solves this problem and provides the ability to find insights using Power BI cross-filtering.

## What it is for:
* Availability of active NDCs on the market.
* Studying chronic shortages by *drugs, substances, NDCs.

## Who will find it useful:
* Sourcing specialist.
* Supply chain analyst
* Buyers
* Retailers
